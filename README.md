# 💰 Expenses Tracker

A clean, fast, single-page expenses tracker built with vanilla HTML/CSS/JS — no frameworks, no build step.

## Features

- ✅ Add income and expense transactions with categories
- 📊 Spending-by-category bar chart
- 📅 Month-by-month navigation
- 🔍 Filter by type (All / Income / Expense) + keyword search
- 💾 Data persists in browser localStorage (no backend needed)
- 🌙 Dark-mode themed UI
- 📱 Responsive layout

## Categories

**Expenses:** Food · Transport · Housing · Health · Entertainment · Shopping · Utilities · Education · Other

**Income:** Salary · Freelance · Investment · Gift · Other Income
